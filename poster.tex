 \section{Hardware-accelerated science}
 Machine learning is becoming a standard part of the modern scientist's toolkit.
 As a result, the use of \textbf{hardware accelerators} (e.g.\ GPUs) in scientific software workflows is increasingly common.
 Historically, GPU-enabled software could be difficult to work with and required expertise to deploy.

 \subsection{Reproducible environments with Pixi}
  \begin{center}
   % Kept small to leave room for the lock file excerpts
   \href{https://pixi.prefix.dev/}{\includegraphics[width=0.30\textwidth]{tools_pixi.pdf}}
  \end{center}
 \begin{itemize}
  \item Declaratively create \textbf{fully reproducible locked environments} with \textbf{conda} packages (ANY language) and \textbf{Python} packages
  \item Locking: digest-level, automatic, Rust-fast~\emoji{1f680}
  \item Define host-specific expectations of hardware resources (e.g.\ CUDA version)~\emoji{26a1}
  \item Resolve environments for \textbf{multiple platforms} other than solve machine (e.g.\ solve on ARM-based Mac laptop, run on x86\_64 Linux machine with CUDA stack from conda-forge)
 \end{itemize}

 \vspace{1.0em}

 \begin{itemize}
  \item Deploy software environments to HTC, HPC, and cloud (e.g.\ HTCondor, Slurm, and Kubernetes) worker nodes through Apptainer and Docker \textbf{Linux container images}
  \item With Pixi environment, Apptainer definition files \& Dockerfiles become \textbf{simple~templates}
  \item \emoji{1f4a1}~\textbf{Leverage CI/CD pipelines}: Changes to environment can trigger rebuilds and redeployments of container images (from PR merge to using new containerized environment in production in less than 10 minutes)
  \item \emoji{26a0}~\textbf{Know your compute}: Still need to be thinking if target compute resources drivers and CUDA compute capabilities support software environments
 \end{itemize}

 \subsection{Applications in DSI-driven science}
 Data scientists and researchers at the \textbf{University of Wisconsin--Madison Data Science Institute} are using these workflow patterns across:
 \begin{itemize}
  \item High energy physics applications of simulation-based inference
  \item End-to-end agentic pipeline for nuclear fusion device optimization (\href{https://github.com/driftless-star/driftless-star}{\textcolor{linkblue}{github.com/driftless-star/driftless-star}})
  \item Large-scale simulation of protein motions using molecular dynamics
  \item Reinterfacing high-resolution rapid refresh weather data (\href{https://github.com/UW-Madison-DSI/weather\_api}{\textcolor{linkblue}{github.com/UW-Madison-DSI/weather\_api}})
 \end{itemize}
