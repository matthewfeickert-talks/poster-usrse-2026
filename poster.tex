 \section{Hardware-accelerated science}
 Machine learning is becoming a standard part of the modern scientist's toolkit.
 As a result, the use of \textbf{hardware accelerators} (e.g. GPUs) in scientific software workflows is increasingly common.
 Historically, GPU-enabled software could be difficult to work with and required expertise to deploy.

 \subsection{Reproducible environments with Pixi}
  \begin{center}
   \href{https://pixi.prefix.dev/}{\includegraphics[width=0.5\textwidth]{tools_pixi.pdf}}
  \end{center}
 \begin{itemize}
  \item Declaratively create \textbf{fully reproducible locked environments} with \textbf{conda} packages (ANY language) and \textbf{Python} packages
  \item Locking: digest-level, automatic, Rust-fast
  \item Define host-specific expectations of hardware resources (e.g. CUDA version)
  \item Resolve environments for \textbf{multiple different platforms} than solve machine (e.g. solve on ARM-based Mac laptop, run on x86\_64 Linux machine with CUDA)
 \end{itemize}

 \begin{itemize}
  \item Deploy software environments to HTC, HPC, and cloud (e.g. HTCondor, Slurm, and Kubernetes) worker nodes through Apptainer and Docker \textbf{Linux container images}
  \item With Pixi environment, Apptainer definition files or Dockerfiles become a \textbf{simple template}
  \item \textbf{Leverage CI/CD pipelines}: Changes to environment can trigger rebuilds and redeployments of container images (PR merge to using new containerized environment in production in less than 10 minutes)
 \end{itemize}

 \subsection{Applications in DSI driven science}
 Data scientists and researchers at the \textbf{University of Wisconsin--Madison Data Science Institute} are using these workflow patterns across:
 \begin{itemize}
  \item High Energy Physics applications of simulation-based inference
  \item Plasma physics end-to-end pipelines for transport-consistent stellarator optimization (\href{https://github.com/driftless-star/driftless-star}{\textcolor{linkblue}{github.com/driftless-star/driftless-star}})
  \item Large-scale simulation of protein motions using molecular dynamics
  \item Reinterfacing high-resolution rapid refresh weather data
 \end{itemize}
